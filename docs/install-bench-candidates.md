# Install-bench candidate set

Generated by `scripts/install/agent/eval/bench/Select-Bench.ps1` from `candidates.csv`; do not edit by hand.
200 repositories with difficulty 7 or more (rubric v1, discount 0.2), grouped by category, hardest first.
Scores are from each project's documented install, before installing it; they are rescored after the install.
Factors: 1 machine footprint, 2 machine-specific adaptation, 3 moving parts, 4 configuration and hidden knowledge (each 0 to 3).
